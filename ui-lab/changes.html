What the polish layer changes

Every change in ui-lab/polish.css, with the value before and after. All numbers are rendered sizes in px: the first is a 375 px phone and the second is desktop. "→" inside a cell means the value scales smoothly between the two.

P2Typography

Fewer type sizes, a consistent line height and better line breaks.

WhatBeforeAfterWhy
Hero title (h1)40 / 64, line-height 1.1040 → 64, line-height 1.08, letter-spacing −0.02emLarge serif type looks looser than it is, so slightly tighter tracking reads as more refined.
Section titles (h2)32 / 48, line-height 1.2032 → 44, line-height 1.1548 px was louder than the rest of the type scale. Steps of 1.25 between sizes feel calmer.
Section title underline80 × 4 px, 10 px below56 × 3 px, 12 px belowA thinner, shorter line is quieter and works as an accent rather than a bar.
Serif sub-headings (name, service, publication, ČAP, CTA, "Kde mě najdete")Four different sizes: 24 / 28 / 32 / 36One size: 24 → 30The same role should have the same size. On phones the name (32) was as big as the section titles (32).
Card titles (benefits, steps, who-for)Inter 20, line-height 1.2, 24 px gap to textInter 20, line-height 1.3, 10 px gap to textA title belongs to its text, so the gap inside the group should be smaller than the gaps between groups.
Body paragraphs (homepage)Mix of 15 / 16 / 17 / 18 px, line-height 1.55 / 1.6 / 1.7 / 1.817 px, line-height 1.65 everywhereOne body style is the single biggest consistency gain.
Lead and section subtitles18–22 px, line-height 1.6–1.717 → 20, line-height 1.6, max 40rem wideSubtitles were nearly heading-sized on phones.
Uppercase labels (Vzdělání, Délka setkání…)13 px, tracking 0.08 / 0.09 / 0.12em13 px, tracking 0.1em, weight 700There were three recipes for the same element.
Label grey (--text-light)#7F8C9A (contrast 3.2:1)#66727F (contrast 4.5:1)Easier to read and passes accessibility contrast. It barely looks different.
Line breaksBrowser defaultHeadings: text-wrap: balance. Paragraphs: prettyAvoids a single word left alone on the last line.

WhatBeforeAfterWhy
